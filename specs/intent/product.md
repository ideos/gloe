# Product intent

Gloe makes typed Python workflows explicit and inspectable for people and agents. Ordinary annotated functions remain the unit of business logic. A small composition language supplies sequencing, branches, execution and validation, without inventing a second domain language.

Target workflows include ETL, reporting, reconciliation, monetary transformations, geospatial preparation, dynamic indicator execution and transactional imports. Database/session ownership, retries, CPU offloading and domain decisions remain explicit Python code.
